# 🚀 جمع‌آوری‌کننده کانفیگ V2Ray — اشتراک پروکسی رایگان و خودکار
### 🛡️ استاندارد بنیادین Goodbaye (Universal Quality Standard)

> **یک گردآورنده‌ی هوشمند، بدون وابستگی و فوق‌العاده بهینه برای جمع‌آوری خودکار کانفیگ‌های V2Ray و پروتکل‌های مشابه.**  
> _An intelligent, dependency-free, and highly optimized collector for automated harvesting of V2Ray configs and similar protocols._

## 🏷️ الگوی ۵ خطی نام کانفیگ‌ها (اصل اول منشور)

نام، ریمارک و تگ هر کانفیگ (VLESS, VMess, Trojan, ShadowSocks, SOCKS5) بدون استثنا دارای این ساختار ۵ خطی استاندارد است:

```text
👉🆔@Goodbaye_filtering
📡[پرچم کشور] [نام کشور به فارسی]
®️[نام شهر یا دیتاسنتر]
🅿️ping:[عدد پینگ واقعی]ms
⚡[قابلیت واقعی] | [نوع پروتکل و نسخه IP]
```

## 🗂️ ساختار فایل‌های مخزن

```text

│   ├── requirements.txt               # وابستگی‌های پایتون (Async + تقویم جلالی)
│   ├── .gitignore                     # ایزوله‌سازی توکن‌ها و فایل‌های کش
│   └── .env.example                   # الگوی متغیرهای محرمانه

├── src/
│   ├── collector_git.py               # موتور اسکن بهینه مخازن گیت‌هاب
```

## 🔐 راهنمای تنظیم Secrets در گیت‌هاب

برای فعال‌سازی خودکار و بدون توقف سیستم، کلیدهای زیر را در بخش **Settings > Secrets and variables > Actions** مخزن خود وارد کنید:

* `GH_TOKEN` : توکن دسترسی شخصی گیت‌هاب (Personal Access Token با دسترسی `repo` و `workflow`).
* `BOT_TOKEN` : توکن ربات تلگرام دریافت شده از BotFather.
* `TARGET_CHAT_ID` : آدرس کانال اصلی شما برای انتشار (`@Goodbaye_filtering`).
* *(اختیاری)* `GH_APP_ID` و `GH_APP_PRIVATE_KEY` : جهت فعال‌سازی چرخش دوگانه توکن برای سقف نامحدود API گیت‌هاب.
