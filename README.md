# 🚀 جمع‌آوری‌کننده کانفیگ V2Ray — اشتراک پروکسی رایگان و خودکار
### 🛡️ استاندارد بنیادین Goodbaye (Universal Quality Standard)

> **یک گردآورنده‌ی هوشمند، بدون وابستگی و فوق‌العاده بهینه برای جمع‌آوری خودکار کانفیگ‌های V2Ray و پروتکل‌های مشابه.**  
> _An intelligent, dependency-free, and highly optimized collector for automated harvesting of V2Ray configs and similar protocols._

<p align="center">
این پروژه با بهره‌گیری هم‌زمان از <strong>مخازن گیت‌هاب</strong> و <strong>کانال‌های عمومی تلگرام</strong> (بدون نیاز به API، ربات یا شماره تلفن)، قدرتمندترین و تازه‌ترین منبع کانفیگ‌های زنده را فراهم می‌کند. تمام فرآیندها به‌صورت <strong>کاملاً خودکار</strong> بر روی خط لوله ایمن GitHub Actions با <strong>شاخص کیفیت سخت‌گیرانه (پینگ واقعی زیر ۵۰۰ میلی‌ثانیه)</strong> اجرا می‌شوند.
</p>

```text
👉🆔@Goodbaye_filtering
📡[پرچم کشور] [نام کشور به فارسی]
®️[نام شهر یا دیتاسنتر]
🅿️ping:[عدد پینگ واقعی]ms
⚡[قابلیت واقعی] | [نوع پروتکل و نسخه IP]
